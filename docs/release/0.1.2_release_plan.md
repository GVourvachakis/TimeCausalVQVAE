# PyPI Release Plan: 0.1.2

This plan describes the manual release procedure for `time-causal-vae` version
`0.1.2`. It does not publish automatically and does not include credentials.

## Scope

Version `0.1.2` is a packaging metadata release for the PyPI project
description. The source README now uses absolute, versioned GitHub links instead
of repository-relative paths that PyPI resolves under
`https://pypi.org/project/time-causal-vae/`.

The release must not include trained weights, checkpoints, generated outputs,
downloaded data, processed empirical data, W&B artefacts, or local result
summaries. Do not commit `dist/`.

## Branch And Version Checks

Prepare the release branch from the packaging fix commit:

```bash
git switch release/pypi-0.1.2
git status --short --branch
```

Confirm that version metadata agrees:

```bash
python - <<'PY'
from pathlib import Path
import tomllib

data = tomllib.loads(Path("pyproject.toml").read_text())
print(data["project"]["version"])
print(data["tool"]["commitizen"]["version"])
print(Path("src/time_causal_vae/version.py").read_text().strip())
PY
```

Expected version: `0.1.2`.

## Link Audit

Audit the README before building:

```bash
python - <<'PY'
from pathlib import Path
import re

text = Path("README.md").read_text()
links = re.findall(r"!?\[[^\]]*\]\(([^)]+)\)", text)
bad = [
    link for link in links
    if not re.match(r"^(https?://|mailto:|#)", link)
]
if bad:
    raise SystemExit("Relative README links remain:\n" + "\n".join(bad))
print(f"README link audit passed: {len(links)} links checked")
PY
```

The expected result is that no relative README links remain.

## Build And Validate

Run from the repository root:

```bash
rm -rf dist build *.egg-info
poetry check
poetry build
poetry run twine check dist/*
python -m venv /tmp/tcvae-012-wheel-test
/tmp/tcvae-012-wheel-test/bin/python -m pip install --upgrade pip
/tmp/tcvae-012-wheel-test/bin/python -m pip install dist/*.whl
/tmp/tcvae-012-wheel-test/bin/python - <<'PY'
import time_causal_vae
print("version", getattr(time_causal_vae, "__version__", "missing"))
from time_causal_vae.experiments.multidim_profiles import select_multidim_profile
print(select_multidim_profile("multifactor_market", "portfolio_tail")["candidate"])
PY
```

Expected artefacts:

- `dist/time_causal_vae-0.1.2-py3-none-any.whl`
- `dist/time_causal_vae-0.1.2.tar.gz`

Run release checks:

```bash
poetry run ruff format --check pyproject.toml README.md CONTRIBUTING.md docs src scripts trained_models
poetry run ruff check src scripts configs docs
poetry run mypy src/time_causal_vae
git ls-files | grep -E '(^dist/|^outputs/|^wandb/|^data/raw/|^data/processed/|\.pt$|\.pkl$|\.npy$|\.npz$|__pycache__)' || true
```

The `git ls-files` command should not report generated data, trained weights,
or local output artefacts.

## Push Branch And Tag

Push the release branch for review:

```bash
git push -u origin release/pypi-0.1.2
```

After review, merge or fast-forward the release commit to the branch that should
own the release source. Then create and push the annotated tag from the exact
release commit:

```bash
git tag -a v0.1.2 -m "Release 0.1.2"
git push origin v0.1.2
```

Verify that the versioned README links are live before publishing:

```bash
python - <<'PY'
from urllib.request import urlopen

urls = [
    "https://github.com/GVourvachakis/TimeCausalVQVAE/blob/v0.1.2/docs/release/0.1.2.md",
    "https://github.com/GVourvachakis/TimeCausalVQVAE/blob/v0.1.2/docs/benchmarks/heston.md",
    "https://github.com/GVourvachakis/TimeCausalVQVAE/blob/v0.1.2/trained_models/multidim_profiles.yaml",
    "https://raw.githubusercontent.com/GVourvachakis/TimeCausalVQVAE/v0.1.2/assets/figures/time_causal_vqvae_pipeline.svg",
]
for url in urls:
    with urlopen(url) as response:
        print(response.status, url)
PY
```

## Optional TestPyPI Rehearsal

Publish to TestPyPI only after the local build and checks pass:

```bash
POETRY_REPOSITORIES_TESTPYPI_URL=https://test.pypi.org/legacy/ \
POETRY_HTTP_BASIC_TESTPYPI_USERNAME=__token__ \
POETRY_HTTP_BASIC_TESTPYPI_PASSWORD=<testpypi-token> \
poetry publish --repository testpypi
```

Verify installation from TestPyPI in a fresh virtual environment:

```bash
python -m venv /tmp/tcvae-012-testpypi
/tmp/tcvae-012-testpypi/bin/python -m pip install --upgrade pip
/tmp/tcvae-012-testpypi/bin/python -m pip install \
  --index-url https://test.pypi.org/simple/ \
  --extra-index-url https://pypi.org/simple/ \
  time-causal-vae==0.1.2
/tmp/tcvae-012-testpypi/bin/python - <<'PY'
import time_causal_vae
print(time_causal_vae.__version__)
PY
```

## PyPI Publish

Publish to PyPI only after explicit human approval and after the `v0.1.2` tag
has been pushed:

```bash
POETRY_PYPI_TOKEN_PYPI=<pypi-token> poetry publish
```

Alternatively, if a project-scoped PyPI token is already configured outside the
repository:

```bash
poetry publish
```

Do not commit `.pypirc`, Poetry credential files, shell histories, tokens, or
`dist/`.
