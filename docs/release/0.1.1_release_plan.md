# PyPI Release Plan: 0.1.1

This plan describes the manual release procedure for `time-causal-vae` version `0.1.1`. It does
not publish automatically and does not include credentials.

## Scope

Version `0.1.1` is a patch release after device hardening, benchmark documentation expansion,
experimental multidimensional profile metadata, and output-stripped notebook updates.

The release must not include trained weights, checkpoints, generated outputs, downloaded data,
processed empirical data, W&B artefacts, or local result summaries. Do not commit `dist/`.

## Build And Validate

Run from the repository root:

```bash
rm -rf dist build *.egg-info
poetry build
poetry run twine check dist/*
python -m venv /tmp/tcvae-011-wheel-test
/tmp/tcvae-011-wheel-test/bin/python -m pip install --upgrade pip
/tmp/tcvae-011-wheel-test/bin/python -m pip install dist/*.whl
/tmp/tcvae-011-wheel-test/bin/python - <<'PY'
import time_causal_vae
print("version", getattr(time_causal_vae, "__version__", "missing"))
from time_causal_vae.experiments.multidim_profiles import select_multidim_profile
print(select_multidim_profile("multifactor_market", "portfolio_tail")["candidate"])
PY
```

Expected artefacts:

- `dist/time_causal_vae-0.1.1-py3-none-any.whl`
- `dist/time_causal_vae-0.1.1.tar.gz`

Run release checks:

```bash
poetry check
poetry run ruff format pyproject.toml README.md CONTRIBUTING.md docs src scripts trained_models
poetry run ruff check src scripts configs docs --fix
poetry run mypy src/time_causal_vae
git ls-files | grep -E '(^dist/|^outputs/|^wandb/|^data/raw/|^data/processed/|\.pt$|\.pkl$|\.npy$|\.npz$|__pycache__)' || true
```

## Optional TestPyPI Rehearsal

Publish to TestPyPI only after the local build and checks pass:

```bash
POETRY_REPOSITORIES_TESTPYPI_URL=https://test.pypi.org/legacy/ \
POETRY_HTTP_BASIC_TESTPYPI_USERNAME=__token__ \
POETRY_HTTP_BASIC_TESTPYPI_PASSWORD=<testpypi-token> \
poetry publish --repository testpypi
```

Verify installation from TestPyPI in a fresh virtual environment:

```bash
python -m venv /tmp/tcvae-011-testpypi
/tmp/tcvae-011-testpypi/bin/python -m pip install --upgrade pip
/tmp/tcvae-011-testpypi/bin/python -m pip install \
  --index-url https://test.pypi.org/simple/ \
  --extra-index-url https://pypi.org/simple/ \
  time-causal-vae==0.1.1
/tmp/tcvae-011-testpypi/bin/python - <<'PY'
import time_causal_vae
print(time_causal_vae.__version__)
PY
```

## PyPI Publish

Publish to PyPI only after explicit human approval:

```bash
POETRY_PYPI_TOKEN_PYPI=<pypi-token> poetry publish
```

Alternatively, if a project-scoped PyPI token is already configured outside the repository:

```bash
poetry publish
```

Do not commit `.pypirc`, Poetry credential files, shell histories, tokens, or `dist/`.

## Post-Install Verification

After publication, verify installation from PyPI in a fresh virtual environment:

```bash
python -m venv /tmp/tcvae-011-pypi
```

## Git Tag

Create and push the annotated tag after the release commit is ready:

```bash
git tag -a v0.1.1 -m "Release 0.1.1"
git push origin v0.1.1
```

Use `docs/release/0.1.1.md` as the GitHub release-note source. Do not attach trained weights,
processed data, generated outputs, or notebook execution artefacts unless a future release channel
explicitly documents their provenance and licensing.
