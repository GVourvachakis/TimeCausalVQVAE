# Release Notes: 0.1.2

`time-causal-vae` version `0.1.2` is a packaging metadata release that fixes
the project-description links rendered on PyPI.

Install:

```bash
python -m pip install time-causal-vae==0.1.2
```

Package page:

```text
https://pypi.org/project/time-causal-vae/
```

## Highlights

- The README used as the PyPI long description now avoids repository-relative
  links. Benchmark notes, release notes, registry metadata, multidimensional
  profile metadata, the architecture figure, and the licence link point to
  stable GitHub `v0.1.2` URLs.
- This prevents PyPI from resolving links such as `docs/benchmarks/heston.md`
  or `trained_models/multidim_profiles.yaml` under
  `https://pypi.org/project/time-causal-vae/`, where they correctly return
  `404`.
- Package version metadata is bumped consistently across `pyproject.toml`,
  Commitizen metadata, and `src/time_causal_vae/version.py`.

## Public Defaults

S&P500/VIX remains the stable public workflow. Hawkes/SVMHJD remains an
optional research benchmark. The synthetic multifactor market and S&P500
50-stock panel remain experimental multidimensional infrastructure.

No new trained weights, checkpoints, generated samples, token tensors, W&B
artefacts, downloaded data, processed empirical data, or local result summaries
are included in this release.

## Notes

This release is intended to replace the immutable PyPI `0.1.1` project
description, whose relative links cannot be edited in place after publication.
Push the `v0.1.2` tag before publishing to PyPI so that the versioned GitHub
links in the package description are live when the PyPI page appears.
