# Release Notes: 0.1.0

`time-causal-vae` version `0.1.0` is the first public PyPI release of the
TimeCausalVAE package.

Install:

```bash
python -m pip install time-causal-vae
```

Package page:

```text
https://pypi.org/project/time-causal-vae/
```

The PyPI long description for the already-published `0.1.0` distribution is fixed for that
release. README and documentation changes made after publication will appear on PyPI only in a
future package release.

## Stable Features

- Continuous TC-VAE baseline package modules for no-anticipation financial time-series generation.
- Public S&P500/VIX one-dimensional workflow metadata, with S&P500/VIX as the stable default public
  workflow.
- Causal VQ tokenizer and additive causal autoregressive token-prior infrastructure for the public
  S&P500/VIX discrete baseline.
- Synthetic baseline support for Black-Scholes, Heston, and path-dependent-volatility workflows.
- Financial path diagnostics covering distributional distances, volatility, drawdown,
  autocorrelation, tail-risk summaries, condition-bucket checks, token diagnostics, and registry
  selection metadata.
- Console entry points for training, evaluation, tokenizer/prior workflows, checkpoint inspection,
  and model selection.

## Optional Research Benchmark

- Hawkes/SVMHJD is an optional rare-event research benchmark, not the public default. It uses a
  marked Hawkes jump-diffusion simulator with Ogata event simulation and fixed-grid observation.

## Experimental Features

- Experimental multidimensional benchmark infrastructure for synthetic multifactor markets and a
  local-only S&P500 50-stock panel.
- The multifactor synthetic benchmark is a 50-dimensional low-rank factor market with sector
  structure and optional common/sector jumps.
- The S&P500 50-stock panel is local-only, `yfinance`/Yahoo-backed daily data infrastructure that
  is not redistributed.
- RVQ and multi-code tokenizer infrastructure. These paths are included to exercise experimental
  tokenization and prior machinery, not to declare a selected multidimensional model.
- Hidden128 causal conv-transformer token-prior variants retained as research candidates rather
  than public defaults.

## Known Limitations

- No trained weights, checkpoints, token tensors, generated samples, W&B artefacts, or local output
  summaries are shipped with the package.
- Repository quickstart workflows that use `configs/`, `scripts/`, `trained_models/`, or local data
  paths require a source checkout.
- The PyPI wheel includes the importable package and console scripts, but not empirical data or
  generated outputs.
- Clean installs on Linux may fetch large PyTorch dependency wheels depending on the active Python
  version, platform, and package index policy.
- The package is research software for generative modelling diagnostics. It is not a calibrated
  pricing library, trading system, or source of financial advice.
- No multidimensional model is registry-selected in this release.

## Local Data Policy

Downloaded and processed empirical market data must remain local. In particular:

- S&P500/VIX processed data is expected locally under `data/processed/sp500vix/`.
- S&P500 50-stock panel raw and processed files belong under `data/raw/` and `data/processed/`.
- Yahoo-backed or `yfinance`-backed data must not be redistributed or committed.
- Local outputs belong under ignored paths such as `outputs/` and `wandb/`.

## Weights And Artefacts

The `trained_models/` directory contains lightweight metadata and model cards only. It does not
contain weights. Future public model releases should distribute weights through external release
assets or another explicit artefact channel, not through committed repository files.
