# Release Notes: 0.1.1

`time-causal-vae` version `0.1.1` is a patch release for device hardening,
benchmark documentation, experimental multidimensional metadata, and notebook
updates after the first public PyPI release.

Install:

```bash
python -m pip install time-causal-vae==0.1.1
```

Package page:

```text
https://pypi.org/project/time-causal-vae/
```

## Highlights

- Device hardening across the main public training, generation, tokenizer, token-prior, and
  evaluation paths. The package supports selective single-device CPU/CUDA execution where the CLIs
  expose `--device`, while CPU remains the portable fallback.
- Continuous generation now infers the active model device from parameters or buffers when no
  explicit device is supplied.
- `NeuralSDEDecoder` and `CRSigDecoder` fixed random matrices are registered as non-persistent
  buffers so they move with `model.to(device)` without changing checkpoint payloads.
- Benchmark documentation now covers Black-Scholes, Heston, path-dependent volatility,
  S&P500/VIX, Hawkes/SVMHJD, synthetic multifactor markets, and the local-only S&P500 50-stock
  panel.
- Experimental multidimensional profile metadata is available in
  `trained_models/multidim_profiles.yaml` for research notebooks and local inspection.
- Multidimensional EDA and comparison notebooks were added as output-stripped public notebooks.

## Public Defaults

S&P500/VIX remains the stable public workflow. Hawkes/SVMHJD remains an optional research
benchmark. The synthetic multifactor market and S&P500 50-stock panel are experimental
multidimensional benchmarks.

No multidimensional model is registry-selected in `trained_models/model_registry.yaml`, and this
release does not claim a public-selected multidimensional generator. The multidimensional entries
in `trained_models/multidim_profiles.yaml` have `public_default: false` and are local-output-only.

## Data, Weights, And Outputs

No trained weights, checkpoints, token tensors, generated samples, W&B artefacts, downloaded
market data, processed empirical data, or local result summaries are included in the package.

Empirical market data remains local:

- S&P500/VIX processed data is expected locally under `data/processed/sp500vix/`.
- S&P500 50-stock panel raw and processed files belong under `data/raw/` and `data/processed/`.
- Yahoo-backed or `yfinance`-backed data must not be redistributed or committed.

## Notes

The benchmark docs under `docs/benchmarks/` are the source for mathematical formulations, tensor
and condition conventions, train/eval/preprocessing conventions, and empirical data-source policy.
The notebooks are demonstrations and avoid training, download, and evaluation by default.
